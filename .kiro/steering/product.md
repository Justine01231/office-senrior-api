# Product Overview

Office of Seniors API is a comprehensive senior citizen management system that facilitates care coordination between seniors, staff, and administrators.

## Core Features

- **User Management**: Multi-role authentication system (admin, staff, senior) with approval workflows
- **Health Records**: Track medications, appointments, conditions, tests, vaccinations, allergies, and exercise/therapy sessions with recurring reminders
- **Benefits Management**: Application workflow for government benefits (SNAP, Medicare, Housing) with document tracking and status history
- **Programs & Enrollments**: Community program management with application and enrollment tracking
- **Appointments**: Scheduling system with reschedule request workflow
- **Staff Assignments**: Staff-to-senior assignment management with coverage tracking
- **Notifications**: Real-time notification system for seniors
- **Reports**: Analytics and reporting for administrators

## User Roles

- **Admin**: Full system access, approves seniors and staff, manages assignments
- **Staff**: Department-specific access (health_records, benefits, general), manages assigned seniors
- **Senior**: Profile management, view health records, apply for benefits/programs, request appointments

## Key Workflows

- Senior registration requires admin approval
- Staff can be assigned to seniors by admins
- Benefit and program applications follow pending → approved/rejected workflow
- Appointment reschedule requests require staff approval
- Profile completion tracking for onboarding
